# PrimeiroPasso

Gerador de currículos gratuito para jovem aprendiz, estágio e primeiro emprego.

## Publicar no GitHub Pages

1. Entre em **Settings → Pages** neste repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch **main**, pasta **/(root)** e clique em **Save**.
4. Confira o endereço exibido no painel Pages.

Arquivos principais: `index.html`, `style.css` e `app.js`. Dados do currículo são mantidos localmente no navegador; o PDF é gerado com a opção de impressão do navegador.

**Atenção:** a compra do kit digital está desativada; nenhum pagamento é cobrado neste site. Para vender, é necessário integrar checkout e entrega digital separadamente. Não publique materiais premium em um repositório público.
